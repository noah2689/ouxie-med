# 瓯械健康

> 家庭健康管理微信小程序 · UI/UX 作品集 Demo

[![微信小程序](https://img.shields.io/badge/%E5%BE%AE%E4%BF%A1%E5%B0%8F%E7%A8%8B%E5%BA%8F-%E5%8E%9F%E7%94%9F%E5%BC%80%E5%8F%91-07C160)](https://developers.weixin.qq.com/miniprogram/dev/framework/)

一个用于 UI/UX 作品集展示的家庭健康管理微信小程序前端 Demo。支持家庭成员健康指标记录、趋势查看、设备管理和 AI 辅助解读等核心流程。

> ⚠️ 本项目为前端 Demo，不接真实后端、不接真实设备、不调用真实 AI，所有数据使用本地 mock 数据。

---

## 功能预览

| 页面 | 核心功能 |
|---|---|
| **健康首页** | 今日概览、2×2 指标卡片（血压/血糖/尿酸/设备）、今日提醒 |
| **添加记录** | 底部弹窗、类型切换、手动输入/设备同步、保存后首页更新 |
| **指标详情** | 核心测量值、趋势图、时间筛选、最近记录 |
| **全部记录** | 类型/时间筛选、日期分组、空状态 |
| **成员切换** | 底部弹窗切换、首页数据跟随变化 |
| **家庭成员** | 成员卡片、状态标识、切换成员 |
| **设备管理** | 已连接设备、推荐设备、模拟连接流程、设备同步记录 |
| **提醒设置** | 提醒列表、开关切换 |
| **AI 助手** | 今日解读、快捷问题、打字机回复、历史会话 |
| **我的** | 用户档案、健康档案、功能入口、数据跟随成员 |

## 项目结构

```
ouxie-med/
├── app.js                 # 全局数据
├── app.json               # 页面路由 + 3 Tab 配置
├── app.wxss               # 全局样式 Token
├── images/                # 图标资源（PNG + SVG 源文件）
├── mock/
│   └── health.js          # 完整 Mock 数据
├── utils/
│   └── format.js          # 工具函数
├── components/
│   ├── add-record-sheet/  # 添加记录弹窗
│   ├── member-switch-sheet/ # 成员切换弹窗
│   └── ai-drawer/         # AI 会话抽屉
└── pages/
    ├── health/            # 健康首页（Tab）
    ├── ai/                # AI 助手（Tab）
    ├── my/                # 我的（Tab）
    ├── detail/            # 指标详情
    ├── records/           # 全部记录
    ├── family/            # 家庭成员
    ├── device/            # 设备管理
    └── reminder/          # 提醒设置
```

## 技术栈

- **框架：** 微信小程序原生（WXML + WXSS + JavaScript）
- **数据：** 本地 Mock 数据
- **图标：** Lucide 风格 SVG/PNG
- **无依赖：** 不使用任何第三方 UI 库或框架

## 快速开始

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 克隆项目：
   ```bash
   git clone https://github.com/noah2689/ouxie-med.git
   ```
3. 在开发者工具中导入项目目录 `ouxie-med/`
4. AppID 选择「测试号」（`touristappid`，已在 `project.config.json` 中配置）
5. 点击编译即可预览

## 文案安全规范

本项目为家庭健康管理工具，**不是医疗问诊产品**。

- ❌ 不使用：诊断、治疗、用药、处方、疾病名称、患者、病情、医生、问诊
- ✅ 使用：需要关注、待观察、正常范围、已记录、建议继续记录、趋势说明、记录解读
- ✅ AI 回复边界：仅做记录解读和趋势说明，强调「仅供参考」
- ✅ 所有页面无高风险医疗词汇
